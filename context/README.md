# Central Knowledge Base

Welcome to the centralized knowledge base for **Abdul Kader Khan's** developer portfolio.

## Purpose

This directory serves as the **single source of truth (SSOT)** for all information regarding:
- Developer identity, personal background, and professional goals
- Formal education and learning trajectory
- Technical skill proficiencies and categorizations
- Project portfolio, verified live deployments, and project statuses
- Social profiles and communication links
- Resume location and handling instructions
- Visual and UI/UX design guidelines
- Strict operational protocols for AI coding agents

## Mandatory Rules for AI Agents

1. **Never Invent Information:** Do not fabricate work history, certifications, academic metrics (e.g., CGPA), project features, or external URLs.
2. **Consult Before Modifying:** All website data structures, components, and pages must strictly consume or mirror the data documented in this directory and [`@/data`](../data/).
3. **Preserve Pending Statuses:** Any property marked as `Pending Verification` or `Not provided yet` must remain explicitly pending until provided by the user.
